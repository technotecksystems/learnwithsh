# Learn with SH — Antigravity Build Bundle

Brand: **Learn with SH** · Teacher: **Sir Sahibzada Hammad** (O / AS / A Level Accounting) · Built by **Rayan**

This bundle contains everything needed to continue the build from the approved single-file HTML prototype into a real product:
public marketing website + student portal + admin dashboard + payments.

## How to use it (60 seconds)
1. Open the bundle folder as the workspace in Antigravity.
2. Open `01_reference_html/sir-hammad-academy.html` in a browser. This is the **approved visual and interaction reference** (6 pages, hash-routed).
3. Paste the contents of `00_MASTER_PROMPT.md` into Antigravity as the first prompt.
4. Then run the phases in `06_build_phases/BUILD_PHASES.md` one at a time (do not skip ahead, review each phase).
